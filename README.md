# face_acupoints
the dataset for detecting facial acupoints using mediapipe

for details please refer to the following paper: 
> Xuan Qiao, Yi Yu, Ying-Chen Li, Yao-Yao Fu, Zou-Qin Huang, Liu-Jie Ren, Wei Yao, Facial acupoint localization via dense face landmarks and neural regression, 2026 [under review].

- data: the data folder
- github_example.py: demo code for usage of the dataset
- face_landmark.gif: a visualization of the dataset
